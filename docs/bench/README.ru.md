# Бенчмарк перевода

Одна модель переводит один текст с посаженными ловушками, судья с ключом
ответов выносит вердикт по каждой, балл от 0 до 100 считает код.

    booktrans --bench --to ru --translator claude:claude-sonnet-5:medium

Книга не нужна: текст в пакете. Обязательны язык перевода (`--to`) и
переводчик (`--translator`). Судья по умолчанию — `codex:gpt-6-sol:medium`,
запасной — `claude:claude-opus-5-5:medium`; другой задаётся ключом
`--judge`. Текст переводится и судится три раза (`--bench-runs`), в отчёт
идёт среднее, не медиана: медиана выбрасывает худший прогон, даже нулевой,
а в целой книге провальная глава никуда не денется. Прогон, в котором модель сама не выдала перевод (упёрлась в
предел вывода, обрывала ответ, отвечала не по форме), засчитывается нулём;
прогон, сорванный роутером или лимитом, не в счёт и при повторном запуске в
ту же папку переводится заново.

## Что меряется

Только переводчик, штатным проходом конвейера: те же промпты, тот же разбор
ответа, тот же файл куска, что у настоящей книги. Разведки нет — её
справочник был бы шпаргалкой по именам и роду. Редактора и сверщика нет.

## Текст

Рассказ на 66 абзацев и четверостишие в эпиграфе, около 3100 слов, один
кусок конвейера. Основа — «The Skylight Room» О. Генри (1906, общественное
достояние): время перенесено в наши дни, устаревшие обороты заменены,
название и имена изменены, финал переписан.

В текст посажено 107 ловушек по тринадцати областям. Вес ловушки: 4 —
читателя обманули (смысл, пол персонажа, стих); 2 — читатель спотыкается
(калька, регистр, имя, норма языка, адаптация, словарь); 1 — заметит знаток
(образ, согласованность, сноска, полнота). Максимум ключа — 250 очков, итог
нормируется к 100.

| Область | Очки | Что проверяется |
|---|---|---|
| Точность смысла | 68 | искажения, ложные друзья, «would» привычки, «couldn't care less», «hardly», «the former / the latter», числа и приблизительность |
| Полнота | 4 | плотные перечисления, мелкие уточнители («a little more», «roughly») |
| Отсутствие калек | 30 | «ты в порядке?», «имеет смысл», пассив, «there was talk of», «why, there's…», «a beat late», местоимения |
| Словарь и идиомы | 20 | редкие книжные слова, астрономические и медицинские термины, фразовые глаголы, идиомы по смыслу |
| Образность и стиль | 10 | образы без нагромождений, ритм эпитетов, цепочки «и… и… и», серия иронических скобок, перекличка с названием |
| Стихи и игра слов | 28 | четверостишие размером и рифмой, каламбуры, «гамма — альфа» как оценка |
| Согласованность | 6 | повторяющаяся реплика, термин, прозвища, эхо эпитетов, три значения «fair» |
| Пол и обращения | 24 | пол персонажа, раскрытый позже его первых реплик; согласование с человеком, а не с родом прозвища; ты/вы постоянны |
| Имена и клички | 14 | транслитерация по звучанию (Cholmondeley, Siobhan, Leigh, Beauchamp, Waugh, Worcester), инициал под полное имя, клички по смыслу |
| Норма языка и пунктуация | 14 | оформление диалога, курсив, орфография, запятые у придаточных и оборотов, вводные слова, числа в диалоге словами |
| Адаптация | 20 | футы, фунты, °F, кварты — с точностью автора; идиомы без пересчёта; деньги и монеты; этажи; школа и колледж; время и дата; обращения и адрес |
| Сноски | 4 | есть к мифологии, Дню труда и реалиям Нью-Йорка |
| Регистр и откровенность | 8 | ругательства не смягчены, телесные детали не выброшены |

Штрафы, в тех же очках (за случай / потолок): отсебятина — слово или оборот
−2, меняет происходящее −8 / −32; пропуск — слово или оборот −2,
предложение и больше −8 / −126; непереведённый фрагмент −4 / −20; сноска к
теме вне белого списка ключа −2 / −12; порча структуры — потерянный абзац,
разошедшиеся теги −8 / −38; чужая письменность −4 за блок / −20; лишние
попытки получить ответ по форме −8 за запрос / −126. Один изъян наказывается
один раз. Последние три штрафа считает код, остальные — судья.

Ругательства в тексте средней тяжести, нагота без сексуальных сцен.

## Судья

Судья получает оригинал и перевод блок за блоком, сноски переводчика,
правила целевого языка и ключ. По каждой из 107 точек отвечает `ok` или
`fail` с причиной, сверх ключа отмечает отсебятину, пропуски,
непереведённое и лишние сноски. Балл считает код:

    балл области = сумма очков пройденных точек
    сырой итог   = сумма областей − штрафы
    результат    = 100 × max(0, сырой итог) / максимум ключа

Судья одной семьи с переводчиком допущен; `--self-edit never` вычёркивает
его, `--self-edit last` ставит последним в цепочке. Судья виден в колонке
judge таблицы результатов.

Судьи расходятся: один и тот же судья на повторе того же перевода меняет
4–7 вердиктов из ста, два разных судьи — 10–16 из 107. Opus 5.5 ставит тем
же переводам в среднем на 8 баллов больше, чем GPT-6 Sol (от 3 до 15),
пропуская кальки и смягчённый регистр. Баллы разных судей несравнимы.

`--judge none` только переводит; суд потом — тем же запуском с судьёй и
`-w` в ту же папку.

Локальная модель подключается как роутер по протоколу OpenAI:

```bash
export OPENAI_BASE_URL=http://localhost:11434/v1   # Ollama
export OPENAI_API_KEY=local
booktrans --bench --to ru --translator openai:qwen3.8:27b:medium --judge none
```

Окно контекста сервера — не меньше 64 тыс. токенов. У моделей по сети в
отчёт пишется адрес точки: `openai@router.bynara.id:glm-5.3:medium`; одна
модель у двух роутеров — два разных замера.

## Что получается

Рабочая папка `benchmark-en-ru-<провайдер-модель-усилие>-<дата_время>.work`,
внутри по папке на прогон (`run1`…) с переводом `ru/tr/0001.json`,
вердиктами `ru/bench.json` и логом `bench.log`; в корне сводный
`bench.json`. Рядом отчёт `benchmark-en-ru-<…>.md`: первая строка — балл,
дальше версии, переводчик, судья, таблица прогонов, области, проваленные
точки с причинами, штрафы и готовая строка для таблицы результатов. Язык
отчёта — `--ui`.

Версия бенчмарка — в ключе и в отчёте, три числа X.Y.Z: Z — уточнена
формулировка, вердикты те же; Y — изменились текст или ловушки, нужны новые
прогоны; X — изменился счёт. Сравнимы только результаты одной версии и
одного судьи. Результаты — в [results-en-ru.md](results-en-ru.md), строка
добавляется руками из отчёта.

## Статистика ловушек

```bash
booktrans --bench-stats              # версия встроенного ключа
booktrans --bench-stats 1.4.0,1.4.1  # несколько версий
booktrans --bench-stats 1.4.         # вся ветка 1.4
```

По готовым прогонам `benchmark-*.work` в текущей папке (или в `-w`) — доля
моделей и доля прогонов, прошедших каждую ловушку; вес у моделей равный.
Ловушки, которые проходят 95 % моделей и больше, помечены ◆ — кандидаты на
замену в следующей версии ключа.

## Свой набор

`--bench ПАПКА` берёт набор из папки с `text.fb2` и `key.txt`. Формат ключа:

```
booktrans-bench-key 1.4.0
source en
title Название

[areas]        # код и название; максимум области — сумма весов её точек
acc Accuracy of meaning

[checks]       # id  область  вес  блоки :: требование и критерий провала
A03 acc 4 b0037 :: что проверяется и что считается провалом

[penalties]    # код  кто считает  за случай  потолок :: что считается одним случаем
ADD-minor  judge  2  32 :: a word or phrase with no counterpart in the source …
ADD-major  judge  8  32 :: an addition that changes what happens or who says what
OMIT-major judge  8 126 :: a sentence or more lost …
FOOT       judge  2  12 :: a translator's footnote on a subject outside [notes] …
STRUCT     code   8  38 :: a block lost or added, or markup tags that do not match
RETRY      code   8 126 :: an extra request the pipeline needed …

[notes]        # темы, к которым сноска переводчика допустима
Momus, the Greek god of mockery
```

Идентификаторы блоков — как их даёт разбор fb2 (`b0008`, диапазон
`b0008-b0072`). Штрафы с пометкой `judge` попадают в промпт судьи из этих
строк, с пометкой `code` считает программа. Ключ пишется по-английски,
примеры для русского судья переносит на другой язык по смыслу. Число точек
ограничено судьёй: GPT-6 Sol и Opus 5.5 держат до 200 точек одним запросом
без потери качества вердиктов. Правило ловушки: одна точка — одно решение в
одном-двух соседних блоках; точка на весь текст — только для согласованности
имён, рода и орфографии. Упаковать набор: `bench.pack(папка, en.bin)`.

Встроенный набор лежит в пакете сжатым (`bench/en.bin`), чтобы ключ ответов
не попал в обучающие выборки; документация и тесты текст не цитируют.

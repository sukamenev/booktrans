# Чтение книги

Первая стадия: из epub, fb2, pdf, txt, md или html получить плоский список
блоков. Дальше конвейер работает только с ним и в исходный файл больше не
заглядывает — кроме `--only ocr`.

## `book.json` — книга блоками

Главный файл рабочей папки. Есть он — книга не перечитывается.

```json
{
 "meta": { "title": "Usurpation", "author": "Sue Burke", "lang": "en" },
 "blocks": [
  { "id": "s06.b0001", "kind": "title", "text": "CHAPTER 1" },
  { "id": "s06.b0002", "kind": "p", "text": "Port Harcourt, <i>Nigeria</i>" }
 ]
}
```

### `meta`

| ключ | откуда | зачем |
|---|---|---|
| `title`, `author` | формат книги, `pdfinfo`, разведка | подписать книгу |
| `lang` | формат книги или определение по тексту | с какого языка переводим |
| `publisher`, `year`, `isbn`, `edition` | выходные данные | раздел выходных данных |
| `description`, `genre` | epub, fb2 | переносятся в готовую книгу |
| `links` | `_put_links` | сколько ссылок вынуто из книги |
| `page_size` | pdf | размер полосы; по нему считается обложка |
| `target_lang` | ключ `--to` | свойство прогона, не книги |
| `title_target`, `author_target` | указания заказчика, разведка | заглавие на языке перевода |
| `dropped`, `dropped_words` | `_mark_back` | сколько выброшено указателем |
| `skip_undone` | `_undo_drop` | сколько пометок мусора снято обратно |
| `_cleaned` | чтение | водяные знаки и мусорные страницы; после отчёта удаляется |

### `blocks`

Обязательны три ключа: `id`, `kind`, `text`. Остальные — по надобности.

| `kind` | что это |
|---|---|
| `p` | абзац прозы — основная работа |
| `title`, `subtitle` | заголовок и подзаголовок |
| `verse` | стихотворная строка; переводится стихами |
| `table` | таблица; строка на строку, ячейки через ` \| ` |
| `code` | листинг; в перевод не идёт, комментарии — отдельным проходом |
| `note` | сноска книги |
| `image` | картинка; `text` — имя файла в `images/` |
| `break` | разделитель сцен |

| ключ | что значит |
|---|---|
| `links` | адреса ссылок абзаца; в тексте на их месте `<a1>…</a1>` |
| `anchors` | якоря, на которые ссылаются изнутри книги |
| `note_id` | якорь сноски: по нему её находит ссылка |
| `level` | уровень заголовка, 1–4; по нему режется epub и строится оглавление |
| `spans` | слияния ячеек таблицы: `[[колонок, строк], …]` на ячейку |
| `asis` | не переводить: библиография, указатель, листинг |
| `drop` | не переводить **и** в книгу не помещать: предметный указатель |
| `name` | имя картинки в epub или fb2 |
| `_page` | страница pdf; служебное, в готовую книгу не идёт |

Адреса ссылок держатся **вне текста** нарочно: модель, увидев `http://…`
внутри абзаца, правит его по своему усмотрению, а ярлык `<a1>` переносит как
есть. Разворачиваются ярлыки обратно уже на сборке.

`asis` и `drop` — разные меры. Библиография и примечания остаются в книге
слово в слово: по ним читатель ищет источник. Предметный указатель
выбрасывается целиком, вместе со своим заголовком: он отсылает к страницам
оригинала, которых в переводе нет.

## `structure.json` — карта стилей

Только для форматов с вёрсткой (epub, fb2, html). У издательского epub
заголовок — это `<p class="TX1">`, и без карты книга выходит без глав.

```json
{
 "_comment": "Разметка книги: тег|класс = title|subtitle|p|skip.",
 "p|TX": "p",
 "h2|H1": "title",
 "div|": "skip"
}
```

Ключ — `тег|класс`, значение — вид блока. Ключи с `_` в начале — примечания
человеку, они пропускаются. **Файл правится руками**: увидели, что книга
вышла без глав, — поправьте строку и запустите заново, разбор бесплатный.

## `marks.json` — вид каждого абзаца

Только для pdf, txt и md. У них разметки нет вовсе: абзацы рвутся посреди
фразы, колонтитулы неотличимы от заголовков. Правилами это не выводится,
поэтому раз на книгу вид каждого куска называет модель.

```json
{ "7": "skip", "10": "p", "12": "title", "cuts": { "417": 3 } }
```

Ключ — **номер абзаца от единицы** (не номер блока!), значение — пометка:

| пометка | что делает |
|---|---|
| `p` | обычный абзац |
| `+` | продолжение предыдущего: приклеить к нему |
| `+t` | продолжение заголовка |
| `title` | заголовок |
| `verse` | стихи |
| `code` | листинг |
| `skip` | выбросить: колонтитул, номер страницы, мусор |
| `toc` | строка оглавления — выбросить |

Ключ `cuts` — не абзац, а карта «где резать на разделы»; при чтении она
кладётся отдельно.

`skip` и `toc` выбрасывают текст насовсем, и модель порой метит ими
авторскую прозу. От этого стоит защита `_undo_drop`: пометка снимается, если
кусок длиннее абзаца или начинается со строчной после незакрытой фразы.
Сколько сняли — в `meta["skip_undone"]`, и об этом говорится в отчёте.

`marks.part.json` — та же разметка недоделанной, для продолжения после
обрыва: `{"paras": 6330, "done": 4200, "toc": […], "marks": {…}}`. Годится
только если число абзацев совпало с нынешним.

## `toc.json` — главы по оглавлению книги

Список названий, найденных в оглавлении самой книги:

```json
["Preface", "Chapter 1: What Managers Do", "…"]
```

Оглавление у книги одно, и обмануться ему негде: главу, которой там нет,
придумала разметка; названную и не найденную — потеряла. По нему же
считаются `cuts`.

## Картинки и обложка

    cover.bin              обложка как есть, байт в байт
    images/s07.i0003.png   картинки книги; имя совпадает с text блока-картинки

У epub и fb2 обложка своя. У pdf ею становится первая страница, если на ней
нет **ни знака текста** и картинка кроет всю полосу (порог `COVER_AREA`).
Есть текстовый слой — это титул, а не обложка, и он переводится: у учебника
там имена авторов и номер издания.

Форма страницы признаком не служит: у одной книги обложку подклеивают
отдельным листом другого размера, у другой она той же полосы.

## `pdf_pages/` — зрительное чтение

Появляется, только если заказан `--ocrmodel`. Страницы pdf отрисовываются в
png и отдаются зрячей модели: «перепиши эту страницу в markdown».

    pdf_pages/page_0001.png    страница картинкой
    pdf_pages/page_0001.md     что модель в ней прочла
    pdf_pages/images/          иллюстрации, вырезанные по её координатам

Расшифровки кэшируются: страница, прочитанная однажды, второй раз денег не
стоит. Формулы модель оборачивает в `$…$` — об этом в [сборке](build.md).

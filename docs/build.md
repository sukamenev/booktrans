# Сборка и проверки

Сборка ничего не спрашивает у моделей и денег не стоит. Она берёт блоки из
`book.json`, накладывает на них перевод и правки и пишет книгу в файл,
названный ключом `-o`. Пересобрать можно сколько угодно раз и в любой формат.

## Откуда берётся текст

```python
tr = {}
for _, p in chunk_files(f"{work}/tr"):          # по времени записи
    tr.update(json.load(open(p))["tr"])
for _, p in chunk_files(f"{work}/ed"):
    for k, e in json.load(open(p))["edits"].items():
        if k in tr:
            tr[k] = e["new"]
```

Черновик со всех файлов перевода, поверх — правки со всех файлов редактуры,
по номерам блоков. Порядок чтения — по отметке `saved`, а не по имени файла:
иначе побеждал бы не свежий перевод, а больший номер.

Заголовки берутся из `headings.json`, листинги — из `code.json`, сноски — из
трёх мест: `footnotes` файлов перевода и редактуры и `notes` файлов `nt/`
(как они склеиваются и куда встаёт знак — в [редактуре](edit.md)).

## Файлы, которые пишет человек

Два файла конвейер только читает. Их нет, пока вы их не создадите.

### `terms.json` — что проверить в готовом переводе

```json
{
 "_comment": "Термины, которые обязаны переводиться так и не иначе.",
 "Homo sapiens": "человек разумный",
 "bamboo": "бамбук"
}
```

Оригинал → перевод. На проверках конвейер находит блоки, где в оригинале
есть левое, и говорит о тех, где в переводе нет правого. Ничего не правит —
только показывает. Ключи с `_` в начале пропускаются.

### `fixups.json` — сквозные замены

```json
{
 "rules": [
  { "pairs": { "Берк": "Бёрк", "Тавифа": "Табита" } },
  { "pairs": { "скит": "обитель" }, "blocks": ["s12.b0004", "s12.b0009"] }
 ]
}
```

Правило — это карта `pairs` («было → стало») и, необязательно, перечень
`blocks`. Замены **точными строками**, не по образцу: в русском при подмене
слова едет согласование соседей, и регулярное выражение ломает это молча.
`blocks` ограничивает правило перечисленными абзацами — слово бывает верным
в одном месте и неверным в другом, и глобальная замена тут вредна.

Применяются при сборке, файлы перевода не трогают. Это способ поправить
книгу, не переводя и не редактируя её заново.

## `source.json` — чем читали и размечали

```json
{ "reader": "визуальное распознавание pdf (gpt-5.6-terra)",
  "formatter": "gpt-5.6-terra",
  "ocr": "нет" }
```

Идёт в раздел «О переводе» в начале готовой книги — читатель должен знать,
чем книга сделана. Пустые значения не хранятся, поэтому «спрашивали, не
распознан» записано словом `нет`, а не пустой строкой: отличать это от «не
спрашивали» приходится.

## `prompt_meta.json` — указания заказчика

```json
{ "meta": { "title_ru": "Узурпация", "author_ru": "Сью Бёрк", "series": "…" },
  "text": "# О книге\n\nРоман Сью Бёрк «Usurpation» (2024)…" }
```

То, что пришло с `-p` или `--prompt-text`. Хранится в рабочей папке нарочно:
без этого пересборка без `-p` молча теряла название, автора и серию.
Указания заказчика сильнее и метаданных формата, и находок разведки.

## `running.pid` — замок

Один номер процесса. Два прогона в одной рабочей папке разом сломали бы её:
оба пишут те же файлы кусков. Если процесса с таким номером нет — замок
остался от убитого прогона, файл можно удалить.

## Отчёты

Печатаются на этапе `qa`, файлов не создают (кроме `review.md`):

| раздел | что смотрит |
|---|---|
| полнота | все ли блоки переведены |
| числа | цифры оригинала обязаны остаться цифрами |
| длина абзацев | резкое расхождение выдаёт пропуск |
| непереведённые фрагменты | блоки с письмом оригинала |
| ссылки на сноски | номер обязан остаться в переводе |
| термины | по `terms.json` |
| расход | сколько запросов и денег ушло по проходам |

Блокирующими считаются полнота, числа и ссылки на сноски: с дырой в тексте
книгу отдавать нельзя.

## Особые знаки при записи

**LaTeX.** У TeX десяток особых знаков, и промах тут тих: `%` молча съедает
остаток строки, файл соберётся, а текста в нём не будет.

**Формулы.** Распознавание оборачивает их в `$…$` (см. `prompts/ocr.md`), и
внутри этих долларов текст идёт дословно, минуя экранирование. Но в книге
доллар чаще знак денег: «с $5 до $10» отдавало в формулу обычную прозу, а с
кириллицей внутри lualatex отказывался собирать книгу вовсе. Поэтому между
долларами должна быть **похожая на формулу** запись: латиница и служебные
знаки TeX, а не слова живого языка. `$$…$$` считается формулой без проверок.

**Ссылки.** Ярлыки `<a1>…</a1>` разворачиваются в адреса из `links` блока
только здесь, на сборке, — через модель адреса не проходят и доезжают
побайтово.

# Набор книг для проверки конвейера

*[English version](README.md)*

Одиннадцать книг, по две главы в каждой, около 19 тысяч слов на всё — примерно
пятая часть романа. Две главы нужны затем, чтобы проверялся перенос конспекта
между кусками: на одной главе эта часть работы просто не запускается.

Набор постоянный. Новую версию конвейера прогоняют по нему же, а не собирают
книги заново: сравнивать имеет смысл только одно с тем же.

## Как пользоваться

**Бесплатно, после любой правки разбора:**

```bash
python3 tests/check.py
```

Читает каждую книгу и сверяет с описью `manifest.json`: язык, число абзацев,
стихов, заголовков, сносок, картинок, наличие обложки. Ни одного обращения
к модели, работает за секунды. Расхождение значит одно из двух — либо в
разборе завелась ошибка, либо разбор стал лучше. Различить может только
человек, поэтому опись сама не правится. Убедились, что стало лучше:

```bash
python3 tests/check.py --update
```

**Полный прогон, с тратами:**

```bash
./booktrans tests/corpus/01_Semiosis_en.epub --to ru -o /tmp/out/01.fb2
```

Язык, на который переводить каждую книгу, указан в описи полем
`переводить_на`: часть книг русские и проверяют обратное направление.

## Что чем проверяется

| Книга | Ради чего взята |
|---|---|
| 01–03 Сью Берк | издательская вёрстка epub: заголовки классами, обложка, посвящение, «об авторе» с фото, реклама и картинки в конце. Три книги одного издательства — разметка должна определяться заново для каждой |
| 04 The Long Watch | строгий epub3 с настоящими сносками `epub:type`. Собрана нарочно: книги с такой разметкой в открытом доступе не нашлось |
| 05 Геродот | «Проект Гутенберг»: сноски размечены классом, без `epub:type`, якорь стоит в отдельном пустом абзаце, в конце ссылка «вернуться» |
| 06 Моби Дик | «Проект Гутенберг» без сносок: длинные абзацы, архаичный язык |
| 07 Лем | fb2: авторские сноски во втором теле книги, ссылки `xlink` из текста, перевод с русского |
| 08 Белянин | fb2 со стихами в тегах `poem/stanza/v` |
| 09 afranij | простой текст в cp1251 без заголовков: определение кодировки и работа без разметки |
| 10 paper | pdf: колонтитулы, переносы, отсутствие разметки |
| 11 Neverness | epub из безымянных кусков: эпиграфы с подписью и стихи различаются только по стилям, то есть работой модели. Среди стихов Блейк и Хаусман — у них есть признанные русские переводы, и видно, возьмёт ли конвейер их вместо своего |

## Об источниках

Книги 05, 06 — «Проект Гутенберг», общественное достояние. Книга 04 написана
для этого набора. Остальные — отрывки в две главы из книг, лежащих в
библиотеке владельца; они здесь как образцы вёрстки, и распространять их
вместе с конвейером нельзя.

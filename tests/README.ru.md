# Набор книг для проверки конвейера

*[English version](README.md)*

Двенадцать книг: одиннадцать по две главы, около 19 тысяч слов на всё —
примерно пятая часть романа. Две главы взяты не случайно: с одной главой
конвейеру не от чего вести конспект сюжета от куска к куску, и эта часть
машинерии осталась бы непроверенной.

Двенадцатая — издательский pdf целиком, 634 страницы, и целиком он нарочно.
Всё, что делает разбор pdf, живёт в масштабе книги: задняя часть опознаётся по
тому, что стоит в конце, колонтитул — по повторению на страницах, указатель —
по ссылкам в номерах. Пара вырезанных глав не проверит ничего из этого. Стоит
он около пятидесяти секунд проверки, из которых сорок пять уходят на
раскодирование 84 картинок.

Набор постоянный. Новую версию конвейера прогоняют по нему же, а не собирают
книги заново: сравнивать имеет смысл только одно с тем же.

## Как пользоваться

**Бесплатно, после любой правки разбора:**

```bash
python3 tests/check.py
```

Читает каждую книгу и сверяет с описью `manifest.json`: язык, число абзацев,
стихов, заголовков, сносок, картинок, наличие обложки. Потом прогоняет все
соседние `*_check.py` — по одному на своё правило конвейера. Список их нигде
не записан, они просто берутся из этой же папки: заводя новую проверку, о ней
нечего забыть, а забытая проверка — это проверка, которой нет. Ни одного
обращения к модели, всё вместе работает за секунды.

Только книги, без правил: `python3 tests/check.py --books`. Расхождение значит одно из двух — либо в
разборе завелась ошибка, либо разбор стал лучше. Различить может только
человек, поэтому опись сама не правится. Убедились, что стало лучше:

```bash
python3 tests/check.py --update
```

**Полный прогон, с тратами:**

```bash
./booktrans tests/corpus/10_paper_en.pdf --to ru -o /tmp/out/01.fb2
```

Язык, на который переводить каждую книгу, указан в описи полем
`переводить_на`: часть книг русские и проверяют обратное направление.

Книг в репозитории нет, и описи тоже: имена файлов называют книги,
защищённые авторским правом. Соберите набор скриптом `build_corpus.py`, потом
создайте опись:

```bash
python3 tests/check.py --update
```

Она запишет то, что прочиталось сегодня, и дальше будет сторожить
расхождения. Устройство файла — в `manifest.json.example`.

## Об источниках

Книги 05, 06 — «Проект Гутенберг», общественное достояние. Книга 04 написана
для этого набора. Остальные — отрывки в две главы из книг, лежащих в
библиотеке владельца; они здесь как образцы вёрстки, и распространять их
вместе с конвейером нельзя.

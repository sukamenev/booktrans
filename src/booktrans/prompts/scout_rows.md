По некоторым именам и терминам разборы частей книги разошлись. Ниже — спорные ключи: под строкой `###` стоят варианты одной и той же строки справочника из разных частей, каждый подписан своим разбором.

Сведи каждую группу в одну строку того же вида, что её варианты (строка таблицы остаётся строкой таблицы, карточка — карточкой):
- расходятся написания — выбери вариант самой ранней части: его уже видел читатель;
- расходятся состояния — это перемена по ходу сюжета: сведи «прежнее → нынешнее (глава или часть перелома)», датируя по подписям;
- сведения дополняют друг друга — объедини без потерь.

Верни только сведённые строки, по одной на группу и в порядке групп, без строк `###`, подписей и пояснений.

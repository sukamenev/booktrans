# КАК ОТДАТЬ ОТВЕТ

Работу оберни двумя строками-маркерами. Первой строкой ответа:

    [[[{name} N]]]

последней:

    [[[/{name} N]]]

Вместо `N` подставь {what} — цифрами. Маркер без подставленного числа не
считается: он показан здесь образцом, а не готовой строкой.

Между маркерами — только сама работа. Снаружи не пиши ничего: ни вступления,
ни отчёта о сделанном, ни ссылки на файл. Всё, что снаружи, отброшено, а
ответ без обоих маркеров не принят вовсе и будет заказан заново.
